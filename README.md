# Leadbroker Monitor: versões

Aqui ficam só os instaladores publicados do Leadbroker Monitor. O código não fica aqui.

**Primeira instalação:** abra a [versão mais recente](../../releases/latest) e baixe:
- Mac: o arquivo `.dmg`
- Windows: o arquivo `.exe`

Depois disso o app se atualiza sozinho. Quando sai uma versão nova, ele mostra um aviso, baixa, fecha e abre de novo. As configurações continuam como estavam.

Cada versão vem assinada. O app recusa qualquer arquivo que não tenha sido publicado por quem tem a chave.
